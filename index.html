TL;DR

A humanoid tracks SE(3) end-effector targets with both arms while walking. A geometric admittance controller supplies the nominal arm command; a reinforcement learning policy adds a bounded residual to the arms and commands the legs directly. A five-phase curriculum, a sagittal-plane symmetry prior, and touchdown-aware reward shaping give accurate tracking that stays accurate through footstrike.

Method

Figure 1: System overview.

At each control step the controller forms a geometric SE(3) wrench from the end-effector pose error measured in a ground-heading reference frame, integrates a task-space admittance law, and maps the resulting twist to joint velocities through a damped-least-squares relative Jacobian with a null-space rest-posture projector. The policy adds a bounded residual to that arm command and outputs leg targets directly.

  • Nominal arm controller. Over-damped task-space admittance, giving contact-safe arm motion without learning it from scratch.
  • Residual policy. Bounded corrections on the arms, full authority on the legs, so locomotion and manipulation are learned jointly rather than layered.
  • Ground-heading reference frame. Targets are expressed in a yaw-only frame on the ground, decoupling the manipulation task from pelvis pitch, roll, and height.
  • Symmetry prior. Sagittal-plane reflection enforced as replay-batch augmentation and as an explicit actor-equivariance / critic-invariance loss.

Exact training command — copy-pasteable, anonymized

python -m <pipeline> \
    exp:<experiment> simulator:isaacsim \
    --training.seed 87 \
    --late-arm-dof-vel-weight -0.05 \
    --late-ee-twist-weight -0.05 \
    --reward.terms.penalty_foot_contact_force.weight -2.0 \
    --pretouchdown-vel-weight -2.0 \
    --action.terms.loco_arm_residual.params.controller_kwargs.damping_ratio 2.0 \
    --gait-avg-yaw-leakage -10.0 --gait-avg-lateral -2.0 \
    --randomization.setup_terms.setup_torque_rfi.params.enabled True \
    --randomization.setup_terms.setup_torque_rfi.params.rfi_lim 0.10 \
    --observation.groups.actor_obs.terms.dof_vel.noise 0.05 \
    --ang-vel-sigma-end 0.25 \
    --reward.terms.tracking_ee_pos.params.touchdown_gate_sigma_scale 0.25 \
    --phase-de-iterations 50000 --phase-f-iterations 60000 \
    --phase-teleop --phase-teleop-iterations 60000 \
    --algo.config.use_symmetry_loss True \
    --algo.config.symmetry_actor_coef 5.0 \
    --algo.config.symmetry_critic_coef 0.5
